# Docs-site variant

This folder contains a small set of Markdown pages to demonstrate a docs-style site suitable for GitHub Pages. Put these files in the `docs/` directory and enable Pages from `docs/` in the repository settings.

- `docs/README.md` — Home page
- `docs/getting-started.md` — Getting started guide
